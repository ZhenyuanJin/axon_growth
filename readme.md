# Axon Growth Model

Clone [common_func](https://github.com/ZhenyuanJin/common_func) and replace the `common_func` path in the first cell of each notebook with the path to your local clone.

Run `code/simulation/optimal_results.ipynb` first. Copy the first four generated model directories into `model_timedir_list` in `code/visualization/paper_fig.ipynb`, and use the generated marmoset V4 directory as `marmoset_V4_timedir`. Then run `paper_fig.ipynb` to reproduce the figures.
